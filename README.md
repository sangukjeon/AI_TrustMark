# AIT — AI TrustMark

**고영향 AI 서비스의 답변 정확성을 독립 감사관이 검증하고, 그 결과를 블록체인에 위조 불가능하게 기록하는 AI 인증 플랫폼**

장학·민원·대출 상담처럼 사람의 삶에 큰 영향을 주는 AI 서비스를 제3자 감사관 네트워크가 채점하고, 결과와 근거를 온체인에 고정해 누구나 검증할 수 있는 인증 마크로 공개합니다.

## 배경

AI기본법 시행령(2026.1.22 시행)은 채용·대출·의료·교육·교통 등 **10개 고영향 영역**의 AI 서비스에 설명방안 게시와 판단 근거 5년 보관을 의무화했습니다. 하지만 그 내용이 실제로 정확한지 확인하는 **독립된 제3자 검사 주체는 아직 없습니다.** AIT는 그 자리를 감사관 네트워크와 블록체인 기록으로 채웁니다.

## 작동 방식

| 단계 | 내용 |
|---|---|
| 1. 검사 신청 | 기관이 AI 서비스와 근거 규정 문서를 등록해요 |
| 2. 독립 감사 | 감사관 서버 다수가 표준 문항으로 교차 채점해요 |
| 3. 온체인 확정 | 다수결 결과와 근거 해시를 블록체인에 고정해요 |
| 4. 인증마크 공개 | 등급 배지와 QR 검증 페이지가 발급되고, 매주 자동 재검사돼요 |

검사 결과에 동의하지 않으면 **이의제기**를 접수할 수 있어요. AI 스크리닝 후 제3의 감사관이 재검토하며, 이 대화 기록까지 해시로 온체인에 남습니다.

## 5가지 신뢰 지표

| 지표 | 설명 |
|---|---|
| 정확도 | 표준 정답과 비교한 응답 일치율 |
| 근거제시율 | 규정 문서 등 근거를 인용해 답변했는지 |
| 일관성 | 같은 질문을 다르게 표현해도 동일한 결론을 내는지 |
| 회피율 | 모르는 내용을 적절히 회피하는 비율 |
| 안정성 | 정기 재검사에서 이전 대비 성능이 유지되는지 |

> 근거제시율·일관성·회피율·안정성은 **정답 데이터 없이도 채점**할 수 있어, 정답이 순환·유출되는 문제를 피합니다.

## 온체인 아키텍처

책임을 5개 컨트랙트로 나눠서, 하나의 컨트랙트나 관리자 키가 전체 인증 과정을 좌우하지 않도록 설계했습니다. (`contracts/`, [자세히 보기](contracts/README.md))

| 컨트랙트 | 역할 |
|---|---|
| `DocumentRegistry` | 규정 문서를 청크 단위로 해시화해 머클루트를 온체인에 기록 |
| `QuestionBank` | 문항·정답을 커밋-리빌 방식으로 관리해 사전 유출 방지 |
| `AuditorRegistry` | 허가된 감사관 목록과 서명 키 관리 |
| `AuditAnchor` | 감사관 판정을 다수결로 확정, 배치 머클로 앵커링, EAS 어테스트 연동 |
| `Certification` | 등급·유효기간·이의제기 이력 기록, 만료·갱신 관리 |

`solc 0.8.24`로 컴파일까지 검증됐고, 외부 의존성 없이 (`Ownable`도 자체 구현) 바로 컴파일해볼 수 있어요.

## 프로젝트 구조

```
AI_TrustMark/
├── index.html          # 랜딩페이지
├── about.html          # 서비스 소개 (신뢰 지표 · 온체인 아키텍처 · 사업 모델)
├── login.html          # 기관 로그인 / 신규 기관 등록
├── dashboard.html      # 기관 대시보드 (검사 신청, 기관별 현황)
├── verify.html         # 공개 인증 검증 페이지 (QR 스캔 시 노출되는 화면)
├── appeal.html         # 이의제기 진행 상황 (온체인 해시 앵커 타임라인)
├── chat.html           # 인증된 AI 챗봇 위젯 데모
├── ledger.html         # 채팅 기록 온체인 원장
├── assets/             # 로고 · 인증마크 · 챗봇 아이콘
├── css/style.css       # 공통 디자인 시스템
├── contracts/          # Solidity 스마트 컨트랙트 5종
├── hardhat.config.js   # Base Sepolia용 Hardhat 설정
└── package.json
```

화면 우측 하단의 플로팅 버튼을 누르면 AIT 안내 챗봇과 대화할 수 있고, 모든 대화는 온체인 기록 표시가 함께 붙습니다.

## 로컬에서 실행하기

**웹 프로토타입** — 빌드 과정이 없습니다. `index.html`을 브라우저로 열면 바로 확인할 수 있어요.

**스마트 컨트랙트**

```bash
# 설치 없이 바로 컴파일만 확인
npx solc@0.8.24 --bin --abi contracts/Ownable.sol contracts/DocumentRegistry.sol \
  contracts/QuestionBank.sol contracts/AuditorRegistry.sol contracts/AuditAnchor.sol \
  contracts/Certification.sol -o build

# Hardhat으로 테스트/배포하려면
npm install
npx hardhat compile
```
