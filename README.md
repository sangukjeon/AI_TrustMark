# AIT (AI_TrustMark)

장학, 민원, 대출 상담 등과 같은 고영향 AI의 실제 답변 정확성을 독립 감사관이 검증하고, 그 결과를 블록체인에 위조 불가능하게 기록해 성적표와 인증 배지로 공개하는 AI 인증 플랫폼입니다.

## 배경

AI기본법 시행령(2026.1.22 시행)은 채용·대출·의료·교육·교통 등 10개 고영향 영역의 AI 서비스에 설명방안 게시와 판단 근거 5년 보관을 의무화했지만, 정확성을 확인하는 독립된 제3자 검사 주체는 아직 없습니다. AIT는 그 역할을 감사관 네트워크와 블록체인 기록으로 채웁니다.

## 어떻게 작동하나요

1. **검사 신청** — 기관이 AI 서비스와 근거 규정 문서를 등록합니다.
2. **독립 감사** — 감사관 서버 다수가 표준 문항으로 교차 채점합니다.
3. **온체인 확정** — 다수결 결과와 근거 해시를 블록체인에 고정합니다.
4. **인증마크 공개** — 등급 배지와 QR 검증 페이지가 발급되고, 매주 자동 재검사됩니다.

이의제기가 접수되면 AI 스크리닝 후 제3의 감사관이 재검토하며, 모든 대화 기록은 해시로 온체인에 남습니다.

## 5가지 신뢰 지표

| 지표 | 설명 |
|---|---|
| 정확도 | 표준 정답과 비교한 응답 일치율 |
| 근거제시율 | 규정 문서 등 근거를 인용해 답변했는지 |
| 일관성 | 같은 질문을 다르게 표현해도 동일한 결론을 내는지 |
| 회피율 | 모르는 내용을 적절히 회피하는 비율 |
| 안정성 | 정기 재검사에서 이전 대비 성능이 유지되는지 |

근거제시율·일관성·회피율·안정성은 정답 데이터 없이도 채점할 수 있어, 정답 순환·유출 문제를 피합니다.

## 온체인 아키텍처

| 컨트랙트 | 역할 |
|---|---|
| DocumentRegistry | 규정 문서를 청크 단위로 해시화해 머클루트를 온체인에 기록 |
| QuestionBank | 문항·정답을 커밋-리빌 방식으로 관리해 사전 유출 방지 |
| AuditorRegistry | 허가된 감사관 목록과 서명 키 관리 |
| AuditAnchor | 감사관 판정을 다수결로 확정, 배치 머클로 앵커링, EAS 어테스트 연동 |
| Certification | 등급·유효기간·이의제기 이력 기록, 만료·갱신 관리 |

## 웹 프로토타입

저장소 루트에 정적 HTML/CSS/JS로 만든 프로토타입이 있습니다. 별도 빌드 과정 없이 `index.html`을 브라우저로 열면 바로 확인할 수 있습니다.

- `index.html` — 랜딩페이지
- `about.html` — 서비스 소개 (신뢰 지표·온체인 아키텍처)
- `login.html` — 기관 로그인 / 신규 기관 등록
- `dashboard.html` — 기관 대시보드 (검사 신청, 기관별 현황)
- `verify.html` — 공개 인증 검증 페이지 (QR 스캔 시 노출되는 화면)
- `appeal.html` — 이의제기 진행 상황 (온체인 해시 앵커 타임라인)
- `chat.html` — 인증된 AI 챗봇 위젯 데모
- `ledger.html` — 채팅 기록 온체인 원장

플로팅 버튼(우측 하단)을 누르면 AIT 안내 챗봇과 대화할 수 있고, 모든 대화는 온체인 기록 표시가 함께 붙습니다.
